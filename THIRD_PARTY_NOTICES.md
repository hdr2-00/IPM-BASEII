# Third-party assets

The dashboard embeds [htmx 1.9.12](https://github.com/bigskysoftware/htmx/tree/v1.9.12)
in `internal/webapp/static/vendor/htmx.min.js`. htmx is distributed under
the [Zero-Clause BSD license](https://github.com/bigskysoftware/htmx/blob/v1.9.12/LICENSE).

All other browser assets are stored in this repository. The Go module has
no external Go dependencies.
